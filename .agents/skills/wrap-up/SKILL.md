# Wrap up

Each reply sends the whole thread to the model again, so a long thread uses up the person's plan. A wrap-up ends this thread and leaves a short note, so the next thread starts small.

1. Write from what this thread already holds. Do not read files or run commands to build the list.
2. Reply with what was left unsaid, as a short list in plain words. Put first anything you told the person earlier in this thread that is wrong now. Then look for:
   - something you assumed and did not check,
   - a step you skipped, or a check that did not run,
   - something that may look wrong in the app,
   - a request you did only in part,
   - something you noticed and did not mention,
   - what you would do differently now.

   Skip what is empty. Give each point one or two sentences. When there is nothing, say "Nothing left unsaid."
3. Then follow the handoff skill in `.agents/skills/handoff/SKILL.md`.
